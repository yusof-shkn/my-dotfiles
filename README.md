# My Dotfiles
Personal Hyprland/ML4W customizations.

## Files tracked
- `.config/hypr/conf/custom.conf` — keybinds
- `.config/hypr/scripts/set-terminal-logo.sh` — terminal logo picker
- `.config/fastfetch/config.jsonc` — fastfetch layout
- `.config/ml4w/settings/browser.sh` — default browser
- `.config/zshrc/20-customization` — zsh plugins

## Apply
```bash
cp -r .config ~
```
